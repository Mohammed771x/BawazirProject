# سياق WordOS ونطاق المراجعة

لقطة 11 نوفمبر 2026. بدأ الإعداد عند `c956a29` مع diff محلي، ثم ظهر commit `d365f09` أثناء العمل فأُعيدت مطابقة الحزمة معه ومع ADR-136 واختبار الواجهة الجديد. هذه ليست إثباتًا لما هو منشور. أعد فحص اللقطة قبل التنفيذ.

## النظام الفعلي

- Flutter/Riverpod/go_router في `mobile/`: دخول واستعادة كلمة مرور، اهتمامات، تحديد مستوى، جولات إرشادية، Hub، إضافة كلمات وقائمة وتفاصيل، خمس مهارات، مراجعة أسبوعية، إعدادات وإشعارات محلية، ولوحة Owner داخل التطبيق.
- ASP.NET Core 10 في `backend/`: JWT وصلاحيات User/Owner/Analyst، منطق التعلّم والمواعيد، PostgreSQL، analytics، API للإدارة. مصدر تغيير حالة الكلمة هو الخادم.
- FastAPI في `ai-service/`: محتوى وتقييم، تحقق من المعنى، STT/TTS، محلل الإدارة. النماذج والمزودون يحددهم التشغيل؛ يوجد Groq مع مسار Gemini بديل. المجاني للاستضافة لا يعني أن كل نداء AI مجاني.
- React/Vite في `admin-web/`: لوحة عربية على `/admin` تشمل المستخدمين والتعلم والسلوك والاحتفاظ والتغذية الراجعة والقرارات والتغييرات والإشعارات ومحادثات AI.
- `Dockerfile` يجمع API وPython وملفات الإدارة في حاوية واحدة؛ Python على loopback وبعامل واحد، وذاكرة العمليتين مشتركة ضمن سقف الحاوية. تعليقات السعة تفترض مثال 512 MiB، لكنه ليس قياسًا لحد حساب المالك.

## الرحلة والضوابط التي يجب إثباتها

فتح → حساب/دخول → اهتمامات → تحديد مستوى → Hub → اختيار كلمة **بمعناها** → Reading → فجوة → Listening → فجوة → Speaking → فجوة → Spelling → فجوة → Writing → Active مع حدث النضج → إعادة استعمال → Archived عند تحقق الشروط. يستطيع المتعلم حذف كلمته حذفًا منطقيًا وإضافتها برحلة جديدة. Mature يظهر كحدث وتاريخ قبل Active؛ لا تشترط شاشة أو إقامة في حالة منفصلة لا ينفذها النظام.

المعنى الذي يكتبه المتعلم لا يُحفظ عند رفض المدقق (ADR-112)، ولا يوجد تجاوز بالإصرار؛ فقرات المواصفة القديمة التي تسمح بذلك متجاوزة. التعطل أو الوصف غير المكتمل لا يخزّن كلمة جزئية (ADR-129/130/131).

الفجوة الافتراضية يومان. فشل مهارة لا يعيد المهارات السابقة. المستوى المختار ليس المستوى المثبت. المراجعة الأسبوعية والتدريب لا يحركان pipeline؛ للمراجعة حقول قياس خاصة بها. إعدادات `WordOsConfiguration` هي المرجع للحدود؛ اختبر الحدود الدقيقة، مثل ترقية `>= 0.85` مع epsilon في `LevelEngine` لا كلمة «أكبر من» في وصف قديم.

## أحدث نقاط التراجع

1. **آخر تغيير محلي ملتزم، `d365f09` (ADR-136)**: `alreadyAdded` في `/api/words/lookup`، `WordCandidate`، `add_word_screen` وmock، واختبارات في `DictionarySearchTests` و`mobile/test/add_word_already_added_test.dart`. نتيجة المعنى المملوك تعرض «مضافة» وتتعطل إضافتها. الخادم يطابق senseId أو النص مع المعنى، ويستثني Deleted عبر filter. يجب اختبار عزل المستخدمين، معنى آخر للكلمة نفسها، حذف/إعادة إضافة، معنى مخصص، حالة Archived، وتسلسل الردود. ADR-136 موجود الآن في سجل القرارات ويقصر العلامة على `/lookup`؛ `/define` ومرشحو استبدال المعنى يتركونها false. اختبر هذه الحدود والتوافق الخلفي.
2. commit السابق `c956a29`: إيقاف الصوت وcallbacks المتأخرة، ومشغل Listening المشترك؛ ADR-135. سجل التقدم ما زال يصفه «غير ملتزم» بينما Git يراه ملتزمًا. اختبر النسخة الفعلية، لا صياغة السجل.
3. `aa2ce72`: الجولة الإرشادية وتأخير إذن الميكروفون إلى نهايتها وإعادة المحاولة بعد تغيير الإذن؛ ADR-128.
4. `90801ba`: محادثات الإدارة وGroq/Gemini؛ ADR-133/134. وجود migration `AiConversations` محليًا لا يثبت تطبيقها على Neon.
5. Pagination: 20 كلمة أولًا ثم 10، `offset` وترتيب مع Id؛ ADR-127. يلزم API يدعمها قبل العميل الجديد.

## ما يهم الحصة المجانية

ADR-077 يسجل حادثة تاريخية: probes أبقت Neon مستيقظًا. التنفيذ الحالي يفصل `/health/live` الذي لا يستعلم عن DB عن `/health/ready` الذي يحفظ نجاح فحص DB حتى ساعة ويعرض عمره. لا تفترض أن هذه الحادثة سبب تنبيه اليوم، ولا أن جواب ready المخزن يثبت اتصال DB الآن. ونداء live الخارجي قد يبقي تطبيق Render مستيقظًا حتى لو لم يوقظ Neon؛ اختبر المنصتين منفصلتين.

`IntelDataset.LoadAsync` يحمل مجموعات بيانات الإدارة في الذاكرة لكل طلب؛ هذا اختيار موثق لجمهور صغير. اختبر كلفته عند تراكم البيانات بدل اعتباره عيبًا مسبقًا. الصوت، base64، prefetch، الإعادات، glossary repair، محادثات AI، event batches والبناء المتكرر كلها مصادر استهلاك يجب قياسها.

| لم يُختبر في هذه الجولة | الإنتاج، أجهزة حقيقية، قواعد البيانات، المقاييس والفواتير، تنفيذ أي suite، أو صلاحية النشر |

توجد suites للـDomain وAPI وFlutter وPython ورحلات integration. `admin-web/package.json` لديه build/lint/typecheck ولا يعرّف test script وقت المراجعة. لم يظهر runner k6 أو load suite مخصص ضمن الجرد؛ تعليق `ab` في دليل المشروع ليس حملة قياس قابلة للإعادة. لا يعني ذلك أن الاختبارات الأخرى ناقصة أو فاشلة؛ الجولات المختصة تقرر بالدليل.

`source-inventory.tsv` يسجل ملفات المصدر وعدد الأسطر وبصمتها وقت إعداد الحزمة، بعد استبعاد الاعتمادات والمخرجات والمهاجرات Designer/Snapshot. الجرد **ليس شهادة مراجعة كاملة**. على النموذج المنفذ توثيق الملفات والمقاطع التي قرأها فعلًا وإكمال قراءة مسار تخصصه قبل الحكم.
