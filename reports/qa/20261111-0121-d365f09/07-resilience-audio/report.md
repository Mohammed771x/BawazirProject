# 07 — الأعطال والتعافي والصوت

## 1. الخلاصة

- **الحملة:** `20261111-0121-d365f09`، الجزء الثاني · النسخة: `d365f09` مع تعديلات ADR-137.
- **البيئة:**
  - API بنسخة Release على `:5299` مع `wordos_qa`.
  - **الأعطال محقونة** عبر `fault_proxy.py`، وهو وسيط TCP بين الـ API وبين PostgreSQL (`:55432`) وخدمة الذكاء الاصطناعي (`:8199`). الأوضاع: رفض الاتصال، وتعليق بدون رد، وبطء، وقطع الاتصالات المفتوحة.
  - **كل عطل هنا محقون**، وما فيها ولا حادثة حصلت للتطبيق نفسه.
  - خوادم التطوير (`:5199`، `:8099`) وقاعدة `wordos_dev` ما انمسّت.
- **النتيجة:**
  - الخدمة **تكمل وتتعافى بدون فقد بيانات** في كل الأعطال المحقونة.
  - عند انقطاع قاعدة البيانات **يكون الرفض 500 عام بدل 503 مفهوم** (O07-1).
- **ما لم يثبت:**
  - **الصوت والميكروفون على جهاز حقيقي** (المشكلة المبلّغ عنها في ADR-135). ما فيه جهاز Android ولا `adb`، والمحاكي ما يثبت مشكلة صوت.
  - انقطاع الشبكة على الجوال.
  - Docker (ما هو مثبت).
- **قرار النشر:** **لا مانع مثبت.** الصوت على الجهاز **غير مقاس**.

### الحاوية (مراجعة ثابتة، بدون تشغيل)

`docker/entrypoint.sh`:
- يشغّل uvicorn على `127.0.0.1` ثم الـ API.
- `wait -n` يوقف الحاوية لو ماتت أي عملية، فيعيد Render تشغيلها.
- `trap TERM` يمرر الإيقاف للعمليتين.
- **ما قدرت أختبره:** ما فيه Docker، و`bash` في macOS (3.2) ما يدعم `wait -n`.
